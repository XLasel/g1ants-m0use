# Правила для автоматических помощников в коде

Этот файл читают инструменты, которые помогают писать код. Правила те же, что для людей: [CONTRIBUTING.md](CONTRIBUTING.md).

Коротко:

- Ветки `task-<N>-<тема>` от `main`, коммиты в формате `type(scope): description` по-английски.
- Коммиты и pull request — только от имени автора-человека. Не добавлять строки `Co-Authored-By`, подписи инструментов и ссылки на них в сообщениях коммитов, PR и в коде.
- Не коммитить и не пушить без явной просьбы автора.
- Имена в коде — по-английски. Комментарии и KDoc — по-русски. Пишем их для человека, который впервые открыл файл: что здесь происходит и зачем. Не комментируем каждое действие и очевидный код.
- Владельцы модулей: `speech` — роль 2, `diarization` — роль 3, `summary` — роль 4, `app` и `pipeline` — роль 1. Правки в чужом модуле описывать в PR, чтобы владелец их видел.
- Контракт между обработкой и интерфейсом: модели данных и события обработки (`PipelineEvent`). Меняется только по согласованию.
- Ничего не отправлять в сеть: приложение работает офлайн, облачные API запрещены условиями задания.
- Модели и сборки не класть в git.
