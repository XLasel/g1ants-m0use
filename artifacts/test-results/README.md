# Артефакты тестирования

`results.csv` содержит только известные измерения команды с указанием источника
и границы замера. Пустой `wer_percent` означает отсутствие проверенного эталона,
а не нулевую ошибку. Исторический debug-бенч не выдаётся за финальный release.

`summary-host.json` и `summary-host-long.json` — прежние реальные прогоны LLM
на компьютере; это не обработка аудио на телефоне.
`summary-injection-host.json` — отдельный реальный прогон Qwen на выдуманном
тексте с инъекцией. `summary-injection-control-host.json` — контрольный разговор
без атакующей реплики. Сырые ответы модели, хеши, время, память и проверки
источников сохранены в JSON; смысловой разбор — в `docs/TEST_RESULTS.md`.

Для итоговой сдачи команда добавляет результаты чистой установки release APK
на телефоне: холодный и повторный прогоны, время до расшифровки и до конспекта,
пиковую память, имя/хеш APK и модели, проверку экспорта в авиарежиме.
