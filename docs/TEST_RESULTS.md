# Методика и результаты тестирования

## Диаризация

### Перенос на Kotlin сверен с Python-прототипом

Эталон снят скриптом `src/android/diarization/scripts/dump_reference.py` на трёх записях: русский диалог на 3 спикера (2,1 мин), VoxConverse `kpjud` на 8 спикеров (2,3 мин) и синтетический диалог (10,4 мин). Тесты: `cd src/android/diarization && ../gradlew test`, 24 теста.

| Проверка | Результат |
|---|---|
| Лог-мел признаки | Расхождение не больше 2·10⁻⁶ |
| Эмбеддинги, кэш спикеров после каждого из 34 чанков | Совпадают точно |
| Вероятности от эмбеддингов Python | Расхождение не больше 1,2·10⁻⁷ |
| Вероятности от звука | Изменилось 0,02–0,15% решений «говорит»; сам Python от шума 10⁻⁶ в признаках меняет до 0,34% |
| Реплики на вероятностях Python | 96 из 96 совпадают |
| Вся цепочка на Kotlin, 10,4 мин | 841 из 841 слова с тем же спикером, что у прототипа |
| Скорость на компьютере, 4 потока | RTF около 0,04 |

### Качество на тестовом наборе и с шумом

48 записей: 6 VoxConverse, 6 русских диалогов из аудиокниг и 36 их версий с шумом (`voicerec-poc/testset/build_noisy.py`). Метрики по итоговым репликам: доля слов с верным спикером, DER реплик с допуском 0,25 с, доля записей с верным числом спикеров. Скрипты: `src/android/diarization/scripts/tuning/`.

| Условие | Слова с верным спикером | DER реплик | Число спикеров угадано |
|---|---|---|---|
| Чистые русские диалоги | 100% | 0,7% | 100% |
| Розовый шум 15 / 5 дБ | 100% / 100% | 0,8% / 1,1% | 100% |
| Реверберация | 99,6% | 1,3% | 100% |
| Телефонная полоса | 91,0% | 11,2% | 83% |
| Чужие голоса на фоне 15 дБ | 90,0% | 12,0% | 17% |
| Чужие голоса на фоне 5 дБ | 59,0% | 51,8% | 0% |
| VoxConverse | 97,3% | 17,3% | 67% |

DER реплик на VoxConverse выше, чем DER самой диаризации (2,5%): реплика включает паузы до 2 с между словами, а GigaAM не распознаёт английский. Медиана расхождения границ реплик на чистых русских диалогах: начало 0,07 с, конец 0,12 с.

Ограничения проверки: русские диалоги собраны из аудиокниг (разные микрофоны у дикторов, нет перебиваний), записей жюри мы не видели. Скорость и память на телефоне — в результатах замеров роли 2 после сборки APK с диаризацией.
