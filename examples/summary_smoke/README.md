# Ручной текст для проверки LLM

Это выдуманный разговор, набранный вручную. Аудиозаписи за ним нет: файл
проверяет только генерацию, JSON-грамматику, ссылки и закрытие настоящего GGUF.
Он не является результатом ASR, замером качества диаризации или настоящей записью
для демонстрации жюри.

Смысловые ориентиры при просмотре результата: Анна проверяет JSON к 19:00,
Игорь собирает APK после проверки, показ завтра в 10:00. Решение о скорости
ещё не принято; нельзя подставлять выдуманный результат замеров.

`long-transcript.json` — те же шесть реплик, повторённые шесть раз с разными
временными отметками. Это технический тест разбиения и отбора при контексте
1024 токена; повторение не моделирует качество настоящего длинного разговора.
Отчёт `artifacts/test-results/summary-host-long.json` содержит все реальные вызовы
LLM, их число и размер промптов. Вызов с `--context-size 1024` воспроизводит проверку.
